# تطبيق إدارة توجيه تخصص الكهرباء - محافظة الإسماعيلية

تطبيق ويب متكامل لإدارة شؤون توجيه تخصص الكهرباء، مبني على **Firebase Authentication + Firestore**.

## الميزات الرئيسية

- **3 أدوار**:
  - **موجه (Super Admin)**: صلاحيات كاملة على كل شيء + إدارة المستخدمين والمدارس
  - **مشرف تخصص**: مرتبط بمدرسة واحدة فقط، يرى ويعدل بيانات مدرسته فقط
  - **معلم**: يرى بياناته الخاصة فقط (صحيفته، جدوله، زياراته...) ويمكنه إضافة مواقع إلكترونية

- نظام تسجيل دخول حقيقي عبر Firebase Auth
- شاشات مطابقة للصور المرفقة (بيانات مدارس، ميزانية، صحيفة أحوال، كتب ومراجع، زيارات...)
- طباعة السجلات
- تصدير Excel
- واجهة عربية كاملة (RTL)

## الإعداد

### 1. Firebase Console

1. اذهب إلى Firebase Console → المشروع `dars-37cfc`
2. فعّل Authentication → Email/Password
3. أنشئ مستخدم الـ Super Admin يدوياً:
   - البريد: `a.hfm9999@gmail.com`
   - كلمة المرور: `123456`
4. في Firestore أنشئ مجموعة `users` وأضف وثيقة بنفس UID الخاص بالمستخدم الذي أنشأته، بالمحتوى:

```json
{
  "name": "الموجه العام",
  "email": "a.hfm9999@gmail.com",
  "role": "superadmin",
  "school": "",
  "department": ""
}
```

5. انسخ قواعد الأمان من ملف `firestore.rules` والصقها في Firestore → Rules ثم Publish.

### 2. تشغيل التطبيق

افتح ملف `index.html` مباشرة في المتصفح، أو استخدم خادم محلي:

```bash
cd electric-guidance-app
python -m http.server 8080
```

ثم افتح: http://localhost:8080

### 3. إنشاء مستخدمين آخرين

بعد تسجيل دخول الـ Super Admin:
- اذهب إلى إدارة المستخدمين
- أضف مشرف تخصص واربطه بمدرسة واحدة
- أضف معلمين واربطهم بمدارسهم

## الإدارات والمدارس المدمجة

- شمال: مدرسة الفنية الكهربية الصناعية بنات، مدرسة المهندس ابراهيم احمد عثمان الصناعية بنين
- فايد: مدرسة فايد الصناعية العسكرية بنين
- القنطرة شرق: مدرسة الشهيد المقدم محمد عبدالاله صالح الصناعية بالقنطرة شرق
- القنطرة غرب: مدرسة القنطرة غرب الصناعية بنين، مدرسة القنطرة غرب الصناعية بنات
- ابوصوير: مدرسة الشهيد مجند محمد محمد علي ابراهيم العسكريه المشتركه
- التل الكبير: مدرسة الشهيد احمد عادل وصفي العسكريه المشتركه بالتل الكبير
- القصاصين: مدرسة القصاصين الصناعيه العسكريه المشتركه

## ملاحظات أمنية

- قواعد Firestore تمنع المشرف من رؤية بيانات مدارس أخرى
- المعلم لا يرى إلا بياناته
- اجتماعات المكتب الفني مرئية فقط للـ Super Admin
